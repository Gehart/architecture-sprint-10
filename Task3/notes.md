# Стратегии защиты данных


| **Данные**                | **В чём необходимость защиты**           | **Инструменты защиты**   |
|:--------------------------|:-----------------------------------------|:-------------------------|
| Персональные данные       | Соблюдение 152-ФЗ                        | Шифрование, минимизация, контроль доступа   |
| Медицинские данные        | Сохранение мед. тайны | Шифрование, контроль доступа  |
| Финансовые данные         | Финансовые потери, штрафы                    | Шифрование при передаче, отсутствие хранения этих данных  |
| Коммерческие данные       | Финансовые потери      | Шифрование, контроль доступа   |
